📐 Architecture

  • State: Zustand stores (game, deck, card rules) with localStorage persistence
  • Routing: React Router — /, /lobby, /game/:roomId, /board, /decks, /decks/:id, /tools, /settings, /broadcast
  • Cards: Scryfall API (search, named lookup, /cards/collection batch endpoint)
  • Storage: LocalStorage for all state, backgrounds, deck data — IndexedDB planned
  • Drag & drop: Native HTML5 drag API (hand to battlefield)
  • Multiplayer: Colyseus room server with shared protocol/ package; private hands/libraries are delivered through owner-only messages
