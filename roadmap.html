📐 Architecture

  • State: Zustand stores (game, deck, card rules, toasts) — persisted to localStorage, rules overrides in IndexedDB
  • Routing: React Router — board, decks, deck detail, tools, settings, broadcast, lobby, game rooms
  • Cards: Scryfall API (search, named lookup, /cards/collection batch) with on-demand IndexedDB image caching and 143 bundled local images
  • Rules: Parser extracts abilities from Oracle text → public/all-decks-rules.json feeds the trigger engine for every deck
  • Multiplayer: Colyseus room server + shared mtg-protocol package (types, entry-tap logic); private hands/libraries via owner-only messages
  • Drag & drop: Native HTML5 drag API (hand to battlefield)

🐛 Known Issues

  • Low-frequency "other"-kind abilities (energy counters, gain-control) are parsed but not mechanically resolvable (honest toast shown)
  • Backgrounds stored as data URLs in localStorage (~5MB limit)
  • Multiplayer lacks auth/rate-limiting for public deployment (explicitly out of scope)
