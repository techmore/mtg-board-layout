📐 Architecture

  • State: Zustand stores (game, deck, hand, settings)
  • Routing: React Router — /decks, /board/:deckId, /tools, /settings
  • Cards: Scryfall API for search + image URIs; card data stored locally in IndexedDB
  • Storage: LocalStorage for settings/prefs; IndexedDB for decks and game snapshots
  • Drag & drop: @dnd-kit for moving cards between zones
